# 🟠 Guia de Estilo do Projeto

## 🔵 Sobre o projeto

Este arquivo apresenta o guia visual utilizado no desenvolvimento do projeto. Nele estão definidas as principais características de identidade visual, como tipografia, cores e tamanhos de fonte.

O objetivo é manter um padrão visual em todas as telas, garantindo uma interface mais organizada, agradável e consistente para os usuários.

## 🔤 Tipografia

A fonte utilizada no projeto é a **Poppins**.

Ela foi escolhida por possuir um visual moderno, limpo e de fácil leitura, podendo ser utilizada tanto em títulos quanto em textos e informações da interface.

## 🎨 Paleta de cores

O projeto utiliza cores primárias, secundárias, neutras e cores destinadas a mensagens de status.

### 🟠 Cores primárias

* 🟠 Primário: `#FF6200`
* 🟤 Primário -1: `#CC4E00`
* 🟠 Primário +1: `#FF8133`

### 🔵 Cores secundárias

* 🔵 Secundário -1: `#539AE9`
* 🔵 Secundário: `#267FE3`
* 🔵 Secundário +1: `#1866BE`

### ⚪ Cores neutras

* Light: `#F2F5F7`
* Light -1: `#D3DDE4`
* Dark +1: `#403B3B`
* Dark: `#262323`
* Dark -1: `#0B0A0A`

### 🟢🔴 Cores de status

#### 🟢 Sucesso

* Success -1: `#7BE085`
* Success: `#52D65F`
* Success +1: `#2FC63E`

#### 🔴 Erro

* Danger -1: `#9E1500`
* Danger: `#D11C00`
* Danger +1: `#FF2705`

## 📏 Escala de fontes

Para manter a padronização dos textos, foram definidos diferentes tamanhos de fonte:

* Small: **14px**
* Parágrafo: **16px**
* H5: **18px**
* H4: **24px**
* H3: **28px**
* H2: **34px**
* H1: **40px**

## 🎯 Objetivo

A utilização deste guia de estilo ajuda a manter a identidade visual do projeto, facilitando o desenvolvimento e garantindo que todas as telas sigam o mesmo padrão de cores, fontes e tamanhos.

Dessa forma, a interface se torna mais organizada, consistente e fácil de utilizar.
